Put a video behind your desktop icons.

Auralis plays any video file as your wallpaper on Windows and macOS, using the system’s own video player. Close the window and it keeps playing. Start a game, unplug, or let the computer sleep, and it pauses.

It stays out of your way

A wallpaper should never be the thing you have to manage. This is what Auralis does on its own.

WhenAuralis
You close the Studio windowKeeps playing. Controls live in the tray on Windows and the menu bar on macOS.
A game or video goes full screenPauses until the desktop is visible again.
Your laptop switches to batteryPauses, so the wallpaper doesn’t drain it.
The computer sleeps and wakesPauses before sleep and picks up where it left off.
A new video fails to loadKeeps your previous wallpaper and tells you why.
You plug in another displayRebuilds the wallpaper for the new layout. Each display can have its own video.

Install

You need Windows 10 or 11 (x64), or macOS 13 or later. Builds are free and not code-signed yet, so your system asks once before opening them.

  1. Run the installer

    Open …-windows-x86_64-setup.exe. It installs for your account only, so no administrator rights are needed.

  2. Get past SmartScreen

    If Windows says it protected your PC, choose More info, then Run anyway.

  3. Pick a video

    Drop a video file onto Auralis Studio and choose Set as wallpaper. Uninstall any time from Settings, Apps.

  1. Open the disk image

    Open …-macos-universal.dmg. One app runs on both Apple silicon and Intel Macs.

  2. Drag Auralis to Applications

    Then Control-click Auralis in Applications and choose Open. You only need to do this the first time.

  3. Pick a video

    Auralis lives in the menu bar. Choose Open Auralis Studio, add a video, and choose Set as wallpaper.

Where it stands

Auralis is in beta. Here is what has been checked on real hardware and what still needs testers.

Windows

  • Wallpaper behind desktop icons
  • Hardware video playback with Media Foundation
  • Tray controls and start at login
  • Built and tested on every change
  • Acceptance testing on more Windows setups

macOS

  • Menu bar app and Studio window
  • AVFoundation playback, sleep and display handling
  • Built and tested on every change
  • Wallpaper visibility fix, not yet retested on a Mac
  • Studio window, not yet tested on a Mac
